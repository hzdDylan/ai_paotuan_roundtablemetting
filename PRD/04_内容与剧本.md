# 04 内容与剧本

**一句话：先写一个能玩的《顾先生的晚宴》，只做门廊也能成立。**

---

## 1. 内容策略

- 首版只做 **1 个原创剧本**；
- 先做 **门廊场景**（15–20 分钟），验证玩法；
- 再做完整三幕（45–60 分钟）；
- 不用科比特先生，避免版权风险；
- 剧本要能展示：社交、检定、失败、BP 吐槽、NPC 记忆、多结局。

---

## 2. 《顾先生的晚宴》

### 2.1 Logline

> 1935 年，上海法租界。你们怀疑商人顾先生与连环失踪案有关，决定以邻居身份邀请他赴宴，在觥筹交错间套出真相。但顾先生远比你们警觉——而你们的 BP 队友，也各有各的秘密。

### 2.2 背景

| 项 | 内容 |
|---|---|
| 时间 | 1935 年秋 |
| 地点 | 上海法租界，顾公馆 |
| 氛围 | 潮湿、体面、檀香底下有铁锈味 |
| 传闻 | 半年内 4 人失踪，最后都出现在顾公馆附近 |
| 顾先生 | 丝绸/航运商人，寡言、体面、每周三闭门谢客 |
| 内容分级 | 16+（悬疑/囚禁/心理恐怖） |

### 2.3 玩家角色（3 选 1）

| 原型 | 强项 | 本场目标 |
|---|---|---|
| **记者 Joe** | 话术、心理学 | 套出顾先生与失踪案的关系 |
| **侦探 林** | 侦查、心理学 | 找到证据/失踪者下落 |
| **学者 沈** | 心理学、话术 | 确认顾先生的“收藏”是什么 |

### 2.4 BP 队友（MVP 固定 2 个）

#### Stella（社交名媛）

| 项 | 内容 |
|---|---|
| 性格 | 体面、精明、怕被拒绝 |
| 本场目标 | 让顾先生接受邀请，维持“体面邻居”人设 |
| 秘密 | 她欠顾先生钱；她曾帮顾先生“介绍”过人 |
| 关系 | 信任你；提防老陈；对顾先生又怕又恨 |
| 吐槽风格 | 礼貌的阴阳怪气；“……你认真的？” |
| 善变点 | 一旦可能暴露自己，她会退缩/撒谎 |

#### 老陈（顾先生旧账房）

| 项 | 内容 |
|---|---|
| 性格 | 谨慎、贪财、记仇 |
| 本场目标 | 拿回能敲诈顾先生的账本 |
| 秘密 | 他知道地下室；偷了钥匙 |
| 关系 | 觉得你是“有用的傻子”；不信任 Stella |
| 吐槽风格 | 直、损、看热闹不嫌事大 |
| 善变点 | 为了账本，他可以卖队友 |

### 2.5 NPC

| NPC | 目标 | 秘密 | 态度 | 吐槽/反应 |
|---|---|---|---|---|
| **顾先生** | 保护秘密、维持体面 | 地下室关着失踪者 | 礼貌但警惕；对 Stella 有旧交情 | 冷面、客气、话里有话 |
| **管家阿福** | 保住饭碗 | 知道地下室，不敢说 | 礼貌、回避 | 紧张、答非所问 |
| **巡警老周** | 别惹事 | 收了顾先生的钱 | 多一事不如少一事 | 打官腔、和稀泥 |

## 3. 三幕

### 场景 1：门廊（MVP）

| 项 | 内容 |
|---|---|
| 目标 | 让顾先生接受晚宴邀请 |
| 时钟 | 顾先生耐心 3（失败社交 -1；到 0 关门） |
| 线索 | 刚结束会面 / 袖口有泥 / 檀香与铁锈味 / 管家口误“楼下” |
| 出口 | 接受邀请 → 晚宴；拒绝但观察到线索 → 蹲守/不请自来；强行闯入 → 冲突 |
| 关键检定 | 话术 50、心理学 50、侦查 30、欺骗 50 |

### 场景 2：晚宴

| 项 | 内容 |
|---|---|
| 目标 | 让顾先生说漏嘴/拿到书房线索 |
| 时钟 | 晚宴时间 4；顾先生疑心 3 |
| 线索 | 书房照片 / 顾先生不吃荤 / 管家口误 / 老陈偷钥匙 / “周三的客人” |
| 出口 | 拿到地下室线索 → 场景 3；被逐客 → 街上；冲突 → 战斗/逃跑 |
| 关键检定 | 话术 30、心理学 50、侦查 30、欺骗 50、闪避 50 |

### 场景 3：书房/地下室

| 项 | 内容 |
|---|---|
| 目标 | 找到证据/救出失踪者/活着离开 |
| 时钟 | 仪式进度 5；巡警 4 |
| 线索 | 失踪者名单 / 符咒 / 暗道 / 顾先生的“交易” |
| 出口 | 揭露 / 交易 / 逃离 / 仪式完成 |
| 关键检定 | 格斗 50、闪避 30、心理学 30、侦查 50、话术 30 |

## 4. 结局

| 结局 | 条件 | 调性 |
|---|---|---|
| **A 揭露** | 拿到证据 + 救出人/报警 | 正义但代价高 |
| **B 交易** | 与顾先生谈判 + 放弃部分真相 | 灰色，活下来但不安 |
| **C 逃离** | 自保 + 成功离开 | 生存，真相未明 |
| **D 仪式完成** | 仪式进度到 5 | 坏结局，续作钩子 |

## 5. 本剧本的吐槽示例

| 你说 | GM | BP |
|---|---|---|
| “我把顾先生变成鸡。” | “你伸手去抓顾先生的领子。他后退半步，看你的眼神像在看一个喝多了的远房亲戚。” | Stella：“……Joe，你认真的？我们还在人家门口。” |
| “我掏枪。” | “你摸到腰后的枪。顾先生的目光落在你手上，慢慢把门开大了一点——像是怕你走火。” | 老陈：“行，你开枪，我负责收尸。” |
| “我用话术让他自杀。” | “你刚开口，顾先生就笑了。他问你，是不是最近戏看多了。” | Stella：“这主意烂得我都想替你投个骰子。” |
| “我原地睡觉。” | “你靠着门框闭上眼。顾先生看了你三秒，转头问 Stella：‘你朋友还好吗？’” | Stella：“……我假装不认识他。” |
| “我要把房子点了。” | “你摸出火柴。顾先生看着你，没说话，只是把手背到身后——你听见了枪套扣打开的声音。” | 老陈：“烧可以，先把我那份账本拿出来。” |

**要求：** 每局至少 1 次 BP 吐槽、1 次 BP 拒绝或善变；不要句句抬杠。

## 6. 内容规范

- **短**：GM 1–3 段，NPC 1–2 句，BP 1–3 句；
- **具体**：写“袖口有泥”，不写“他很可疑”；
- **有潜台词**：顾先生不说“我在藏人”，说“楼下不方便待客”；
- **不 AI 味**：避免“突然/仿佛/不禁/空气中弥漫着”；
- **不出戏**：不写“我是 AI/作为语言模型”；
- **安全**：不写露骨性内容、虐待细节、未成年人伤害；暴力点到为止。

## 8. 内容生产

1. 人工写骨架：目标/时钟/线索/分支/结局；
2. AI 填充：对话/描述/选项；
3. 人工审校：一致性/信息边界/节奏；
4. 自测 3 局：记录卡点/无聊点/意外点；
5. 调整难度/线索/角色目标；
6. 冻结，进入开发。

**原则：骨架人工写，AI 只做填充。**
