# 03 功能需求

## 2. P0 功能

### 2.1 首页

| ID | 功能 | 验收 |
|---|---|---|
| F-01 | 五个按钮：选择剧本 / 游戏说明 / 记忆回廊 / 制卡 / 设置 | 顺序固定；跑团风格；单手可点 |
| F-02 | 选择剧本页 | 只有 2 个按钮：顾先生的晚宴 / 自定义剧本；内置：有角色→跑团，无角色→先制卡；无 API→提示设置/看示例归档；自定义：MVP 只做入口，显示“开发中”，形态待设计 |
| F-03 | 游戏说明 | 3 页以内：怎么玩 / 骰子 / 吐槽与拒绝 |
| F-04 | 记忆回廊 | 历史归档列表；可读/回放/开放/导出/删除 |
| F-05 | 设置 | API key、模型、文字速度、归档隐私、关于 |

### 2.2 制卡（我的）

| ID | 功能 | 验收 |
|---|---|---|
| F-10 | 基础属性 | 力量、敏捷、意志、体质、智力、魔法、幸运、外貌；点数分配 |
| F-11 | 技能 | 神话、侦查、心理学、话术；可扩展闪避/格斗/射击 |
| F-12 | 派生属性 | HP/MP/SAN 自动计算并显示 |
| F-13 | 外观 | 上传 1 张图片；方形裁剪；可换；无图用首字母 |
| F-14 | 随身物品 | 3–5 个格子；名称 + 一句话描述；可在跑团中使用 |
| F-15 | 保存/编辑 | 保存后成为“我的”；可再次编辑 |
| F-16 | 选择剧本 | 校验点数/姓名；保存后进入剧本选择页 |

### 2.3 跑团

| ID | 功能 | 验收 |
|---|---|---|
| F-20 | 桌子 | 显示参与人数（如 4/6）、你的座位、BP 座位、GM 位 |
| F-21 | BP 渲染 | 头像/首字母、名字、状态（说话/思考/沉默） |
| F-22 | 底部对话框 | 左上角显示说话人；正文为当前会话；逐字显示 |
| F-23 | 右侧插话按钮 | 常驻；AI 说话时可点；点击后暂停 AI、展开输入 |
| F-24 | 自由输入 | 说话/行动；发送后进入对话流 |
| F-25 | 建议行动 | 3 个建议；点击即发送；可换一批（有限） |
| F-26 | 骰子卡 | 技能/目标/骰值/结果；大成功/大失败有区别 |
| F-27 | 记录 | 打开完整 transcript；主界面只显示当前句 |
| F-28 | 场景切换 | 目标达成/时钟满 → 转场；有转场文本 |
| F-29 | 存档 | 每 beat 自动保存；可继续 |

### 2.4 GM / BP 行为

| ID | 功能 | 验收 |
|---|---|---|
| F-30 | GM 吐槽 | 用旁白/NPC 反应吐槽离谱行为；不系统提示 |
| F-31 | BP 吐槽 | 每个 BP 都会吐槽；风格符合角色 |
| F-32 | BP 拒绝 | 可以拒绝玩家计划，给出角色理由 |
| F-33 | BP 善变 | 可改主意，但有可推断原因（怕/贪/嫉妒/自保） |
| F-34 | 不出戏 | 不说“我是 AI/作为语言模型” |
| F-35 | 信息边界 | BP/NPC 不知道不该知道的秘密 |
| F-36 | 骰子权威 | GM 不能改骰子结果 |

### 2.5 归档

| ID | 功能 | 验收 |
|---|---|---|
| F-40 | 自动归档 | 一局结束生成：transcript、骰子日志、角色卡、关键选择、结局、时间 |
| F-41 | 默认私密 | 不开放时只在本地 |
| F-42 | 开放开关 | 每个归档单独开关；开放后出现在“公开”列表/可导出 |
| F-43 | 回放 | 可按 beat 回看 |
| F-44 | 导出 | Markdown/JSON；用于分享/评估 |
| F-45 | 示例归档 | 仓库内置 1 个真实归档；无 API 也能读 |

### 2.6 设置

| ID | 功能 | 验收 |
|---|---|---|
| F-50 | API key | 本地保存；可测试连接；可清除 |
| F-51 | 模型 | GM/BP 可分别选；默认便宜模型 |
| F-52 | 文字速度 | 快/中/慢/瞬间 |
| F-53 | 归档隐私 | 默认私密；可改 |
| F-54 | 关于 | 版本、License、致谢 |

## 3. P1 / P2

- 1 真人 + 3–5 BP；
- 完整三幕《顾先生的晚宴》；
- 多结局；
- 记忆回廊公开页/分享卡片；
- 回退一 beat；

- 角色立绘。

### P2（v1.0）

- 剧本编辑器；
- iOS；
- 多人真人（不考虑）。

### 待定

- **自定义剧本**：MVP 只保留入口，具体形态（表单/生成/编辑器）待设计，不在本版本承诺。

## 5. 验收标准（P0）

### 5.1 四屏

- [ ] Android 竖屏，首页/选择剧本/制卡/跑团四屏可走通；
- [ ] 首页五个按钮顺序正确，跑团风格；
- [ ] 选择剧本页只有 2 个按钮：顾先生的晚宴 + 自定义剧本；
- [ ] 自定义剧本 MVP 只显示“开发中”；具体形态待设计；
- [ ] 无角色点内置剧本 → 先制卡；有角色 → 进跑团；
- [ ] 制卡页含 8 基础属性、4 技能、1 张图、随身物品；
- [ ] 跑团页有桌子、人数、BP 渲染、底部对话框、右侧插话按钮。

### 5.2 一局

- [ ] 3 分钟内进入第一句对话；
- [ ] 15–20 分钟完成门廊场景；
- [ ] 至少 1 次检定、1 次失败、1 次补位、1 次吐槽；
- [ ] 至少 1 次 BP 拒绝或善变；
- [ ] 结束时生成归档。

### 5.3 插话

- [ ] AI 说话时按钮可点；
- [ ] 点击后 AI 暂停，输入框展开；
- [ ] 发送后 AI 有反应；
- [ ] 记录里能看到“你打断了 X”。

### 5.4 骰子

- [ ] 显示技能/目标/骰值/结果；
- [ ] 大成功/大失败边界正确；
- [ ] GM 不能改结果；
- [ ] 日志可查。

### 5.5 归档

- [ ] 自动生成，含 transcript/骰子/角色/结局；
- [ ] 默认私密；
- [ ] 可开放/关闭/导出/删除；
- [ ] 无 API 可读示例归档。

### 5.6 无 API

- [ ] 点内置剧本时提示“需要 API”；
- [ ] 可去设置填 key；
- [ ] 可看示例归档；
- [ ] **没有 Mock 模式**。

## 6. 不做

真人多人 / 语音房 / 3D / VTT / UGC / 自定义剧本生成（MVP 仅入口）/ Mock / 桌面端 / iOS 首发 / 账号系统 / 云同步。
