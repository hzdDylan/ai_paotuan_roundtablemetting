# 一人成团（Party of AIs）— PRD

**v0.2 · 2026-10-21 · Android 优先 · 个人项目**

---

## 一句话

> **一个真人，混在一群 AI 玩家里跑团。**

1 个真人 + 2–5 个 **BP（Bot Player，AI 玩家）** + AI GM，真实 d100 骰子；剧情由 AI 之间互相沟通推进；你可以随时插话；GM 和 BP 都善于**吐槽、拒绝、善变**。

---

## 四个界面

| 界面 | 一句话 |
|---|---|
| **首页** | 选择剧本 / 游戏说明 / 记忆回廊 / 制卡 / 设置 |
| **选择剧本** | 《顾先生的晚宴》+ 自定义剧本，共 2 个按钮 |
| **制卡（我的）** | 属性 + 一张外观图 + 随身物品 |
| **跑团** | 桌子 + 底部对话框 + 右侧插话按钮 |

详细线框见 [05_体验与界面](05_体验与界面.md)。

---

## 一局怎么跑

1. 首页 → 选择剧本；
2. 剧本选择页：内置《顾先生的晚宴》或「自定义剧本」，共 2 个按钮；
3. 有角色 → 直接上桌；无角色 → 先制卡；
4. 桌子上坐着你、2–5 个 BP、GM（NPC 临时入座）；
5. 底部对话框显示“谁在说话”；
6. 你随时可以点右侧「插话」打断 AI，改变流程或触发意外；
7. 需要判定时，GM 要骰 → 真实 d100 → 结果决定成败；
8. 一局结束，自动归档到「记忆回廊」，是否开放由你决定。

## 核心设定

| 项 | 设定 |
|---|---|
| 平台 | **Android 优先**（Flutter，竖屏）；iOS 后续；不做桌面端 |
| 人数 | 1 真人 + 2–5 BP + 1 GM；NPC 不计入队伍 |
| 骰子 | d100 roll-under；技能 1–99；大成功 01–05，大失败 96–100 |
| 语气 | GM/BP 必须会吐槽；可拒绝、可善变；不说教、不出戏 |
| 插话 | 右侧常驻按钮；任何时候可打断 AI，插入自己的话 |
| 归档 | 每局自动生成团本历史；默认私密，可开放/导出 |
| 无 Mock | 没有 API 就不能实时生成；仓库提供**真实示例归档**供阅读 |

---

## MVP

- 1 个原创剧本：《顾先生的晚宴》；
- 1 个场景：门廊（15–20 分钟）；
- 1 真人 + 2 BP（Stella / 老陈）+ GM + 1 NPC（顾先生）；
- 四屏：首页 / 选择剧本 / 制卡 / 跑团；
- d100 检定 + 骰子卡；
- 插话 + 吐槽 + 拒绝；
- 团本历史归档；
- 设置（API、模型、文字速度、归档隐私）。

---

## 不做什么

商业发行 / 真人多人联机 / 语音房 / 3D / VTT 地图 / UGC 市场 / 自定义剧本生成（MVP 仅入口）/ Mock 模式 / 桌面端。

## 关键决策

| # | 决策 | 结论 |
