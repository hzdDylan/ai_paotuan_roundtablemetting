# 02 核心玩法

**一句话：你坐在桌子这头，对面是 GM，旁边是几个会吐槽你的 BP。**

---

## 1. 角色

| 角色 | 谁 | 数量 | 干什么 | 不能干什么 |
|---|---|---|---|---|
| **你** | 真人 | 1 | 说话、行动、插话、做决定 | 不能替 BP 行动 |
| **BP** | AI（Bot Player） | 2–5（MVP 2） | 以自己的角色身份说话/行动、吐槽、拒绝、善变 | 不能替别人说话、不能决定骰子、不能知道隐藏信息 |
| **GM** | AI | 1 | 描述世界、扮演 NPC、判检定、推进节奏、吐槽 | 不能替玩家决定、不能改骰子 |
| **NPC** | AI（GM 调度） | 每场 1–3 | 有自己的目标/秘密/态度 | 不能知道不该知道的 |
| **Director** | 系统 | 1 | 决定谁说话、切场景、给谁 spotlight、防冷场 | 不参与演出 |

> **BP = Bot Player，AI 扮演的跑团玩家。** 不是 NPC，不是 GM，是和你一起坐在桌边的“人”。

---

## 2. 一局的结构

```
选剧本 → 上桌（你 + BP + GM）
  → 场景（目标 / 时钟 / NPC）
    → 回合：谁说话 → 行动 → 检定 → 结果 → 状态
  → 场景结束 → 下一场景 / 结局
  → 归档到「记忆回廊」
```

- 单场景：10–20 分钟；
- 单局：15–20 分钟（MVP 门廊）→ 45–60 分钟（完整三幕）；
- 单 beat：1–3 分钟。

---

## 3. 回合怎么走

```
1. Director 选下一个说话的人
2. 他说话/行动
3. 要判定？GM 要骰 → d100 → 结果 → GM 叙述
4. 更新状态：态度/时钟/线索/关系
5. Director 判断：继续 / 给真人 / 插事件 / 转场
```

**谁先说话：** 不是严格轮流，是 **spotlight**——当前最相关、最有戏、最久没说话的人。真人每 2–3 个 beat 至少轮到一次。

---

## 4. 骰子

**d100 roll-under：**

- 技能 1–99；
- 骰值 ≤ 技能 = 成功；
- 骰值 > 技能 = 失败；
- 01–05 大成功；96–100 大失败；
- 困难 = 技能减半；极难 = 技能 1/5。

**流程：**

```
你/BP 声明行动
  → GM 声明：技能 + 难度 + 目标 + 失败后果
  → 真骰子（服务端）
  → 显示：技能 / 目标 / 骰值 / 结果
  → GM 叙述，不能改结果
```

**原则：GM 先声明，骰子后出，GM 再叙述。** 不允许“先写结果再补骰子”。

## 5. 吐槽、拒绝、善变（核心）

### 5.1 为什么要有

玩家（你）一定会做刁钻、随机、恶搞的事：把 NPC 变成鸡、对BOSS表白、在严肃场合跳舞、试图用话术让对方自杀。

如果 GM/BP 只会“好的，你成功了”，游戏 3 分钟就无聊。**吐槽是这款游戏的灵魂。**

### 5.2 谁要会

- **GM 必须会**：用旁白/NPC 反应吐槽，冷面、简短、有画面；
- **每个 BP 都必须会**：吐槽是共性；**怎么吐槽**取决于角色；
- **NPC 可以不会**：NPC 可以严肃、迟钝、听不懂，反而更好笑。

### 5.3 三种反应

| 反应 | 是什么 | 例子 |
|---|---|---|
| **吐槽** | 不阻止，但用角色的话点破荒唐 | “你认真的？我们还在人家门口。” |
| **拒绝** | 不配合，给出角色理由 | “我不干。你要发疯别拉上我。” |
| **善变** | 改主意，但有原因（怕/贪/嫉妒/自保） | 先答应帮忙，发现会暴露自己后反悔 |

### 5.4 吐槽的规则

**GM：**

- 用世界反应吐槽，不直接说“这不允许”；
- 冷面、短句、有画面；
- 不评价玩家本人，只评价行为；
- 不破坏世界规则。

**BP：**

- 用角色口吻吐槽；
- 可以翻白眼、叹气、后退、假装不认识你；
- 可以拒绝、可以谈条件、可以阴阳怪气；
- 吐槽完仍然可以帮忙，也可以不帮。

**禁止：**

- 说“我是 AI/作为语言模型”；
- 说教/讲道理/系统提示；
- 人身攻击、歧视、低俗；
- 每句话都吐槽（会腻）。

**频率：** 每场景 1–2 次高质量吐槽即可，不要句句抬杠。

### 5.5 吐槽示例

| 你说 | GM | BP |
|---|---|---|
| “我把顾先生变成一只鸡。” | “你伸手去抓顾先生的领子。他后退半步，看你的眼神像在看一个喝多了的远房亲戚。” | Stella：“……Joe，你认真的？我们还在人家门口。” |
| “我掏枪。” | “你摸到腰后的枪。顾先生的目光落在你手上，慢慢把门开大了一点——像是怕你走火。” | 老陈：“行，你开枪，我负责收尸。” |
| “我用话术让他自杀。” | “你刚开口，顾先生就笑了。他问你，是不是最近戏看多了。” | Stella：“这主意烂得我都想替你投个骰子。” |
| “我原地睡觉。” | “你靠着门框闭上眼。顾先生看了你三秒，转头问 Stella：‘你朋友还好吗？’” | Stella：“……我假装不认识他。” |
| “我要把房子点了。” | “你摸出火柴。顾先生看着你，没说话，只是把手背到身后——你听见了枪套扣打开的声音。” | 老陈：“烧可以，先把我那份账本拿出来。” |

### 5.6 善变的规则

BP 可以改主意，但必须有**可推断的原因**：

- 怕了（NPC 威胁/局面失控）；
- 贪了（有人出更高价）；
- 嫉妒（你抢了她的功劳）；
- 自保（再帮你会暴露她的秘密）；
- 关系（你之前帮过/坑过她）。

**不是随机翻脸。** 玩家事后应该能说：“她翻脸是因为……”

### 5.7 拒绝的规则

- BP 可以拒绝你的计划；
- 拒绝要给角色理由；
- 可以谈条件（“除非你告诉我真相”）；
- 可以退出场景（“我在楼下等你们”）；
- 不能直接“系统禁止”。

---

## 6. 插话

- 屏幕右侧常驻「插话」按钮；
- 任何时候可点，包括 AI 正在说话时；
- 点击后：AI 暂停 → 输入框展开 → 你说 → AI 反应；
- 插话可以：改变话题、阻止行动、提出新计划、触发意外、吐槽回去；
- 插话有代价：可能打断 BP 的计划、惹恼 NPC、错过信息。

**这是你和 AI 抢方向盘的方式。**

---

## 7. 场景与时钟

每个场景有：

- **目标**：你要达成什么；
- **时钟**：3–5 格，失败/拖延会推进；
- **出口**：达成/失败/离开去哪。

**失败前进：** 失败不是卡住，是“更糟/更复杂”：NPC 更警惕、时钟 -1、线索带代价、计划暴露。

**MVP 不做硬性 game over**，除非最终场景。

---

## 8. 你必须会遇到的时刻

1. BP 先上，失败；你补位，成功；
2. 你做了离谱的事，GM/BP 吐槽你；
3. BP 拒绝你的计划，或跟你谈条件；
4. BP 因为自己的秘密/利益，突然改主意；
5. NPC 记得你上次的冒犯，态度更冷；
6. 大失败暴露计划，时钟加速；
7. 时钟到 0，NPC 离开，但留下一条线索；
8. 一局结束，归档里能看到“你做过最离谱的事”。

## 9. 示例（门廊）

```
GM：你们按了门铃。顾先生开门，站在阴影里。
顾先生：两位，有什么事吗？

BP Stella：您好，顾先生，我是 Stella，刚搬到隔壁。
  我们想办个小餐会，希望您能赏光。
  （请求【话术】）

GM：普通难度，目标 50。失败他会礼貌拒绝。
骰子：81 → 失败。

顾先生：按礼节，我不该拒绝一位女士。但我刚结束一场会面，实在疲惫。

【你点「插话」】
你：不会耽误您太久，就是吃点点心。Stella 说您是本区有名的实业家。

GM：普通难度，目标 50。
骰子：41 → 成功。

顾先生：……好吧。我换件衣服就过去。
```

**如果这时你说：“顺便，我能把你变成鸡吗？”**

```
GM：顾先生正在扣外套扣子，手停了一下。他看向 Stella，像是在确认自己是不是听错了。
BP Stella：……他开玩笑的。顾先生，他今天出门没吃药。
```

---

## 10. 防冷场

- 连续 2 轮 BP 对 BP → 把话筒给你/插事件；
- 你 3 个 beat 没说话 → 提示你；
- 连续 3 次没新信息 → GM 推进时钟/给线索；
- 每场景最多 8–15 beat，目标达成/失败就转场；
- BP 每句 1–3 句，禁止长篇大论。
