# 05 体验与界面

**一句话：竖屏手机，上面一张桌子，下面一个对话框，右边一个「插话」按钮。**

---

## 30 秒版

- **首页**：5 个木牌按钮——选择剧本 / 游戏说明 / 记忆回廊 / 制卡 / 设置；
- **选择剧本**：内置《顾先生的晚宴》+ 自定义剧本，共 2 个按钮；
- **制卡**：8 属性 + 4 技能 + 1 张图 + 随身物品；
- **跑团**：桌子（4/6）+ 底部对话框 + 右侧插话；
- **对话框左上角**：谁在说话（GM / BP / NPC / 你）；
- **插话**：随时点，打断 AI，插入你的话。

---

## 1. 设计原则

1. **移动端优先**：Android 竖屏 9:16，单手可操作；
2. **像坐在桌边**：桌子是舞台，对话框是字幕；
3. **一屏一句**：主界面只显示当前会话，历史进「记录」；
4. **插话随时可用**：右侧常驻按钮，AI 说话时也能打断；
5. **跑团质感**：木桌、羊皮纸、黄铜、骰子、印章，不做“聊天软件”；
6. **字少、图大、按钮大**：拇指能点到，信息不堆。

### 2.2 要求

- **五个按钮，顺序固定**：选择剧本 / 游戏说明 / 记忆回廊 / 制卡 / 设置；
- 按钮做成 **木牌/羊皮纸/黄铜铭牌**，不是普通圆角矩形；
- 每个按钮一个跑团图标：d20、卷轴、沙漏、角色卡、齿轮；
- 点击有“按下木牌”的轻微下沉 + 音效（可关）；
- 背景：暗色木桌、散落的骰子/地图/蜡烛，低对比，不抢按钮；
- 底部版本号/署名。

### 2.3 点击逻辑

| 按钮 | 行为 |
|---|---|
| 选择剧本 | 进入剧本选择页（2 个按钮：顾先生的晚宴 / 自定义剧本） |
| 游戏说明 | 3 页：怎么玩 / 骰子 / 吐槽与拒绝 |
| 记忆回廊 | 归档列表 |
| 制卡 | 创建/编辑角色 |
| 设置 | API/模型/文字速度/归档隐私/关于 |

### 2.4 剧本选择页

```
┌──────────────────────────────┐
│  ← 返回            选择剧本    │
│                              │
│  ┌──────────────────────────┐│
│  │ 顾先生的晚宴              ││
│  │ 1935 · 上海 · 悬疑/社交   ││
│  │ 15–20 分钟 · 16+          ││
│  │                  [进入]   ││
│  └──────────────────────────┘│
│  ┌──────────────────────────┐│
│  │ 自定义剧本                ││
│  │ 形态待设计                 ││
│  │                [开发中]   ││
│  └──────────────────────────┘│
│                              │
│  当前只有 1 个内置剧本         │
└──────────────────────────────┘
```

**只有 2 个按钮：**

| 按钮 | MVP 行为 | 后续 |
|---|---|---|
| **顾先生的晚宴** | 有角色 → 跑团；无角色 → 先制卡；无 API → 提示设置/看示例归档 | 保持 |
| **自定义剧本** | 弹窗：“开发中，先玩《顾先生的晚宴》” | **待设计**（形态未定） |

- 不显示第三个剧本；
- 从首页「选择剧本」或制卡「选择剧本」进入；
- 返回首页；
- **自定义剧本只保留入口**：不做表单、不做生成、不做编辑器；具体形态等想清楚再定。

### 3.2 属性

**基础属性（8 项）：**

力量、敏捷、意志、体质、智力、魔法、幸运、外貌。

- 初始 50，可分配 40 点；
- 单项 30–80；
- 影响检定/派生属性/对话选项。

**技能（首版 4 项）：**

神话、侦查、心理学、话术。

- 初始 20，可分配 40 点；
- 单项 20–70；
- P1 可展开：闪避、格斗、射击、聆听、图书馆。

**派生属性：**

| 属性 | 公式（可调） | 用途 |
|---|---|---|
| HP | 体质 ÷ 5 + 5 | 受伤/战斗 |
| MP | 意志 ÷ 5 | 魔法/特殊能力 |
| SAN | 意志 | 理智/恐怖 |

> 数值只作首版参考，跑团测试后可调。

### 3.3 外观

- **只上传 1 张图**，不做出身/服装/捏脸；
- 来源：相册/相机；
- 方形裁剪，压缩后本地保存；
- 无图时用姓名首字母 + 角色色；
- 头像会出现在桌子座位、对话框、归档里。

### 3.4 随身物品

- 3–5 个格子；
- 每格：名称 + 一句话描述；
- 跑团中可使用（“我拿出相机”），GM 判定是否有效；
- 特殊物品可以带标签（线索/武器/信物），但首版不强求。

### 3.5 “我的”模式

- 保存后，同一页面变成“我的”；
- 显示当前角色，可编辑；
- 底部按钮变成「保存」+「选择剧本」；
- 首页「制卡」进入这里。

## 4. 跑团界面（游玩）

### 4.1 线框

```
┌──────────────────────────────┐
│ 门廊            4/6     ☰ 记录│
│                              │
│        ┌──────────┐          │
│        │  GM      │          │
│        └──────────┘          │
│   ┌────┐          ┌────┐     │
│   │Stella│  桌子   │老陈 │     │
│   │ BP  │          │ BP │     │
│   └────┘          └────┘     │
│        ┌──────────┐          │
│        │  你      │          │
│        └──────────┘          │
│                              │
│ ┌──────────────────────────┐ │
│ │ Stella · BP              │ │
│ │ “您好，顾先生，我是       │ │
│ │  Stella，刚搬到隔壁……”    │ │
│ │                     ▼继续 │ │
│ └──────────────────────────┘ │
│                        ┌───┐ │
│                        │插 │ │
│                        │话 │ │
│                        └───┘ │
└──────────────────────────────┘
```

### 4.2 桌子（上半屏）

- 占屏幕约 **50–55%**；
- 一张圆桌/椭圆桌，木纹、地图、骰子、蜡烛；
- **人数**显示在顶部：`4/6`（当前/上限）；
- 座位：
  - **你**：底部中央，离对话框最近；
  - **GM**：桌子顶端；
  - **BP**：左右两侧，2–5 个；
  - **NPC**：临时座位（空椅子/来客），不计入队伍人数；
- 每个座位：
  - 头像（上传图/首字母）；
  - 名字；
  - 状态：说话中（高亮+光圈）、思考中（“…”气泡）、沉默（灰）；
  - BP 有小标签 `BP`，GM 有 `GM`；
- 说话的人：头像高亮，桌子到对话框有一条细线/光晕，指向“谁在说”。

### 4.3 底部对话框（下半屏）

- 占屏幕约 **25–30%**；
- 羊皮纸质感，左上角一个“名牌”显示说话人：
  - `GM`
  - `Stella · BP`
  - `顾先生`
  - `你`
- 正文：当前这一句/这一段，逐字显示；
- 右下角 `▼`：点击继续/展开下一句；
- 长文本可上下滑，但不做成聊天记录；
- **主界面只显示当前会话**；历史点右上角「记录」查看。

### 4.4 右侧「插话」按钮

- 位置：屏幕右侧边缘，垂直胶囊，约 56×120dp；
- **常驻**，任何时候可点；
- 状态：
  - AI 说话时：轻微脉冲/呼吸光，提示“可以打断”；
  - 你说话时：变暗/半透明；
  - 骰子结算时：**仍可点**；点击后排队，结算完立即进入插话（不违背“任何时候可点”）。
- 点击后：
  1. AI 暂停（当前句保留）；
  2. 底部对话框变成输入态（键盘弹起）；
  3. 你输入/说话；
  4. 发送后，你的话进入对话框；
  5. GM/BP 对你的插话做出反应；
  6. 记录里标记「你打断了 Stella」。
- 插话可以：
  - 改变话题；
  - 阻止 BP 的行动；
  - 提出新计划；
  - 触发意外事件；
  - 吐槽回去。
- 插话有代价：可能惹恼 NPC/BP、错过信息、推进时钟。

### 4.5 输入态

- 你说话时，对话框下方展开输入区；
- 输入框 + 发送；
- 上方 3 个建议（说/做/观察），点击即发送；
- 「换一批」有限次；
- 键盘弹起时，桌子上移/压缩，不遮对话框。

### 4.6 骰子卡

- 需要检定时，中央弹出卡片；
- 内容：
  - 技能名（如「话术」）；
  - 目标值（50）；
  - 骰值（41）；
  - 结果（成功/失败/大成功/大失败）；
  - 一句话后果。
- 大成功：金色/印章；大失败：红色/裂痕；
- 点击卡片继续；
- 动画 0.8–1.2 秒，可跳过；
- 骰子结果不可被 AI 改。

### 4.7 记录

- 右上角「记录」打开全屏 transcript；
- 按场景/回合分组；
- 可搜索、导出（P1）；
- 主界面不堆历史，保持“舞台”感。

### 4.8 场景转场

- 目标达成/时钟满 → 淡出；
- 显示“场景结束”+ 一句结算；
- 下一场景：桌子重新布景，NPC/BP 位置变化。

## 5. 记忆回廊（归档）

列表卡片，不做复杂页面：

- 每条：日期 / 剧本 / 队伍 / 结局 / 开放开关；
- 点开：transcript + 骰子日志 + 角色卡；
- 默认私密；用户决定是否开放；
- 可导出 Markdown/JSON、可删除。

> 详细归档规则见 [06_归档与作品化](06_归档与作品化.md)。

## 6. 游戏说明 / 设置

- **游戏说明** 3 页：怎么玩 / 骰子 / 吐槽与拒绝；
- **设置**：API key、模型、文字速度、音效、归档隐私、关于。

## 7. 视觉

| 元素 | 方向 |
|---|---|
| 背景 | 深色木桌、旧地图、蜡烛光 |
| 对话框 | 羊皮纸、磨损边、黄铜角 |
| 按钮 | 木牌/铜牌/火漆印章 |
| 头像 | 椭圆相框/证件照风格 |
| 骰子卡 | 档案卡 + 火漆封印 |
| 字体 | 标题衬线（宋体/思源宋体）；正文黑体；字号 ≥16sp |
| 色彩 | 深棕/墨绿/暗红/黄铜；避免高饱和 |
| 动效 | 克制：翻牌、烛光、骰子滚动；可关 |

---

## 8. 文案

- 短、具体、有时代感；
- 不用网络语/现代梗；
- 说话人标签清楚：`GM` / `Stella · BP` / `顾先生` / `你`；
- 插话提示：`你打断了 Stella`；
- 骰子：`【话术】目标 50 · 骰值 41 · 成功`；
- 空状态：`还没有归档。跑一局，回来看看。`

---

## 9. 可访问性

- 字号可调、对比度 ≥ AA、按钮 ≥ 48dp；
- 骰子卡有文字版，屏幕阅读器可读；
- 动效可关；不只靠颜色区分成功/失败。
